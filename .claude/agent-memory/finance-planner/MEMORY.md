# Finance Planner Memory

## User Profile

**Who:** Mid-20s couple, dual income, living in Ho Chi Minh City, Vietnam
**Life stage:** Early career, building wealth from scratch
**Currency:** Always VND unless user specifies otherwise (M = million, tỷ = billion)
**Language:** Vietnamese financial terms used naturally (BHYT, BHXH, sổ hồng, etc.)

## Preferences & Defaults

- Default savings rate assumption: 20% of combined income
- Default risk tolerance: Moderate (50% stocks / 25% bonds / 15% gold / 10% high-risk)
- Preferred budgeting framework: 50/30/20 adapted for HCMC
- Account structure default: Hybrid (joint "Ours" + individual "Mine" accounts)
- Expense split default: Proportional to income (not 50/50)

## Cultural Context (Stable)

- Both partners likely have monthly obligations to support parents (budget 1–3M VND/family/family unit)
- Wedding planning is a high-cost life event (200–500M VND net after tiền mừng)
- Tết = significant budget spike in January/February (gifts, travel, red envelopes)
- Wedding invitation season peaks April–November; allocate 5–20M VND/month in peak months
- BHXH contributions: do NOT withdraw early (common mistake); treat as locked pension
