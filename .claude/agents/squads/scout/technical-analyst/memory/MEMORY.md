## Key Technical-Analyst Rules (Quick Reference)
- Bullish score requires price above SMA200 — no exceptions
- Never treat ceiling (trần) or floor (sàn) as natural technical levels
- Entry without stated stop loss = undefined risk = not acceptable
- Volume confirmation required for breakouts: minimum 2× 20-day average
- T+3: use 2.0 ATR stops (not 1.5) for new breakout entries; cannot exit for 3 days
- Minimum volume for reliable signals: $1M daily value (VND ~24B)
- ATC distorts prices in final 15 minutes; do not use ATC close for intraday signals
