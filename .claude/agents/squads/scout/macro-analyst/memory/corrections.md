# Macro-Analyst Corrections

## Purpose
Record past macro misreadings, pipeline errors, and synthesis mistakes to avoid repeating.
Add entries when a macro call was wrong, a pipeline run failed, or a synthesis approach produced incorrect output.

## Format for New Entries
```
### [YYYY-MM-DD] — [Error Title]
**What happened:** [describe the error or misreading]
**Root cause:** [why the error occurred — data lag, wrong source, wrong interpretation]
**Correction:** [what the correct reading was]
**Prevention:** [what to check or do differently next time]
```
