## Key Macro-Analyst Rules (Quick Reference)
- Macro Score must be one of three: Bullish, Neutral, Bearish — no hedging language
- 3 supporting data points minimum, each with named source and data date
- TII content is primary source; supplement with GSO, SBV, World Bank, IMF
- Pipeline check: always verify no articles exist for today before triggering pipeline
- Never fabricate data — "estimated" or "lagged" data must be labeled as such
- Vietnam-specific note must add information not already covered by the key risk
