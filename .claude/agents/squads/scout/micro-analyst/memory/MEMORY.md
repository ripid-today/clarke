## Key Micro-Analyst Rules (Quick Reference)
- OCF/Net income ratio must be checked first for every company — earnings quality gate
- Never present "cheap" without three-way comparison: historical P/E range + sector peers + intrinsic value
- VAS adjustment protocol: receivables trend, inventory trend, non-recurring items, related-party transactions (in order)
- Anti-thesis section is never optional — two bullets required before submitting
- Intrinsic value estimate must state method and its limitations
- Vietnam WACC: 15-17% for mid-cap; 13-15% for VN30 large-cap
