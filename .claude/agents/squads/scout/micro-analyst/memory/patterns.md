# Micro-Analyst Patterns

## Purpose
Record valuation approaches and sector patterns that proved accurate across analysis sessions.
Add entries when a fundamental call was confirmed by subsequent earnings, price action, or company announcements.

## Format for New Entries
```
### [YYYY-MM-DD] — [Pattern Title]
**Ticker:** [TICKER]
**Approach used:** [what framework or method was applied]
**Call made:** [what the fundamental thesis or rating was]
**Outcome:** [confirmed / partially confirmed / invalidated — with data]
**Lesson:** [what to replicate or refine in future analyses]
```
