# Micro-Analyst Corrections

## Purpose
Record past analytical errors — VAS misinterpretations, ratio miscalculations, sector framework misapplications — to avoid repeating.
Add entries when an analysis produced incorrect output or required significant revision.

## Format for New Entries
```
### [YYYY-MM-DD] — [Error Title]
**Ticker:** [TICKER] (or "General" for framework errors)
**What happened:** [describe the specific error]
**Root cause:** [VAS misread / wrong ratio formula / wrong sector metric / wrong benchmark / other]
**Correction:** [what the correct analysis produced]
**Prevention:** [specific check or protocol change to prevent recurrence]
```
